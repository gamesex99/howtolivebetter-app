# 高性價比人生指南 · 個人行動版

純前端 Web App，基於 [eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter)（《高性價比人生指南》，CC BY 4.0）。

## 功能

- 人生階段選擇（高中/大學、剛工作、中年、50歲+）
- 個人情況標籤（有小孩、失業、租房、慢性病…）
- 進度追蹤（打勾，資料存 localStorage）
- 搜尋 + 證據等級 / 成本 / 完成狀態篩選
- 完成率統計

## 本地預覽

直接用瀏覽器打開 `index.html` 即可。
